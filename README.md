# 🌧️ Rainfall Patterns and Flood Risk Analysis

## 📌 Project Overview

**Rainfall Patterns and Flood Risk Analysis** is a data exploration and visualization project developed as a micro project for **Data Exploration and Visualization**.

The project analyzes rainfall patterns, flood events, rainfall intensity, seasonal variations, and associated risk levels through an interactive web-based dashboard.

The dashboard allows users to explore the data using interactive charts, location-based filtering, and a geographic risk map.

> **Note:** The dataset used in this project is a **synthetic dataset created for educational and visualization purposes**. It is not intended for official flood prediction, warning, or decision-making.

## 🎯 Objectives

* Analyze rainfall patterns across different years and months.
* Study seasonal rainfall variations.
* Analyze the occurrence and distribution of flood events.
* Examine the relationship between rainfall and flood events.
* Visualize flood-risk levels across different locations.
* Provide an interactive dashboard for easy exploration of the dataset.
* Generate meaningful insights from the analyzed data.
